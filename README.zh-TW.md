# BIOCAGE 自由演化設計（biocage-evo）

[English](README.md) | **繁體中文**

本專案以演化的方式，自由設計一個**用於人類頸椎（C3-C4）、可被身體吸收的 PLCL 支架（BIOCAGE）**。它的任務是在**組織工程椎間盤（生物椎間盤）於體內成熟的期間，提供暫時的支撐與固定**。支架的形狀和材料分布不由人來畫，而是在椎間隙裡「長」出來，再由模擬來評判。另有四個彼此獨立的 AI 代理（設計者、驗證者、安全守門者、找漏洞者），在明確的規則下分別負責發想、檢驗、把關和攻擊。

> **目前狀態（2026-10-26）：** 研究基礎建設階段。GPU 求解器已通過第一批可信度關卡；四個代理中的三個（驗證者、安全守門者、找漏洞者）每天跑一輪；設計者和演化引擎**尚未**啟動，目前還沒有任何設計結果。詳見[目前狀態](#6-目前狀態)。

---

## 1. 研究背景

### 1.1 臨床問題
椎間盤退化是頸痛與下背痛的主要原因之一。末期的治療方式不是融合手術，就是以機械式人工椎間盤做全椎間盤置換。這兩種方式都只處理症狀，而且都和相鄰節段病變有關。組織工程全椎間盤置換的目標，則是讓身體重新擁有一個活的椎間盤。以膠原蛋白纖維環包覆海藻酸鹽髓核的複合工程椎間盤，植入後能和周圍組織整合，並達到接近原生椎間盤的剛度：大鼠需 6 週到 9 個月，狗 16 週，羊 8 週。但在植入當下，它的剛度只有原生椎間盤的十分之一左右，無法獨自承受脊椎的負荷。

### 1.2 為什麼需要支架，以及上一代為什麼失敗
因此，工程椎間盤在成熟期間需要一個**暫時的、可吸收的支撐**。實驗室上一代的嘗試（Lintz 博士論文，Cornell 2021，第 4 章；重點整理見 [`docs/PRIOR_FAILURES_Lintz2021.md`](docs/PRIOR_FAILURES_Lintz2021.md)），是把 3D 列印（熔融沉積）的 PLA 支架植入迷你豬頸椎（C3/4、C5/6，4 週）：

- 兩件式支架一週內就塌陷（椎間高度指數下降 64%）；
- 一件式支架留在原位，但每一個都在後方同樣的兩個位置斷裂，原因是骨頭後方的突起反覆集中施力：這是幾何問題，不是材料問題；
- 用平板均勻壓縮測試時，壓到 134 MPa 都沒壞，預測會成功，結果卻誤導了判斷；
- PLA 在 37°C 培養液中會因水解而變軟；
- 更早的犬隻研究中，植入物在部分節段發生移位：**滑出**是最主要的失敗模式。

### 1.3 前一個模擬研究
母專案（`biocage-stimulation-test-1`）建立了一個經過驗證的人類 C3-C4 功能性脊椎單元 FEBio 模型：26 歲女性頸椎模型（Herron 等人，2020，J Biomech），包含可變形的 C3/C4 骨頭、小面關節接觸和韌帶。它模擬了前路頸椎椎間盤置換手術，並用主動學習篩選兩類由人設計的支架。母專案留下兩個教訓，也是本專案的出發點：(1) 在生理負載下單靠摩擦，所有篩選過的設計都會滑動；(2)「一圈外牆包住中央窗口」這種設計空間太窄。本專案把設計空間完全打開。

### 1.4 支架的目的（怎樣才算成功）
在至少 16 週（另以 26 週做敏感度分析）的期間內，BIOCAGE 必須：維持椎間高度；**不往任何方向滑出**，絕不能往脊髓方向移動；不壓壞終板、不陷入骨頭；並保留足夠的連通空間給生物椎間盤。它不是融合用的支架，也不是永久保留活動度的人工椎間盤。

## 2. 核心想法：讓設計自己長出來

### 2.1 自由的設計空間
- **空間**：在撐開後的 C3 與 C4 終板之間，以 0.2 mm 的小方塊（體素）切分；左右邊界是終板輪廓向內縮 1 mm。支架嚴格限制在椎間隙內，不使用任何刺入骨頭的牙齒、龍骨、螺絲或骨板。
- **材料**：每個小方塊可以是空的，或是 PLCL，並各自決定硬材料比例 φ（0 到 1 之間）。硬材料是 PLCL 85:15（37°C 濕潤狀態下彈性模數約 250–900 MPa），軟材料是 PLCL 50:50（類橡膠，約 1.5–12 MPa），兩者可任意混合，但受限於 3D 列印的解析度（線寬 0.4 mm、層厚 0.2 mm）。撐開高度 d（0.5–1.5 mm）也是演化的變數之一。
- **編碼方式**（三種方式都產生同樣的小方塊場，在同一個資料庫裡競爭）：圖樣生成網路（CPPN，Cheney 等人，2013）；由設計者代理撰寫、再依自動評分演化的小型設計程式（類似 Google DeepMind 2025 年的 AlphaEvolve）；以及模仿骨骼重塑的局部生長與侵蝕。

### 2.2 追求多樣性，而不是單一最佳解
採用 MAP-Elites 資料庫（Mouret 與 Clune，2015），在一張行為地圖上，每一格只保留表現最好的設計。地圖的三個軸是生物椎間盤空間比例、平均硬材料比例和結構類型。這樣做可以讓非常規的設計有足夠時間被驗證，最後交給研究主持人的也是一張取捨圖，而不是唯一答案。

### 2.3 最佳化目標
- **固定（主要目標）**：讓「防止滑出所需的最小摩擦係數」越小越好。取六個生理方向中最差的一個：前屈、後伸、左右側彎、左右旋轉；每次只施加一個方向 1.5 N·m 的純力矩，同時施加 100 N 的跟隨壓力。
- **生物椎間盤空間**：讓連通的空間越大越好（和固定能力互相取捨）。

### 2.4 分層評估
| 層級 | 模型 | 時間 | 用途 |
|---|---|---|---|
| L0 | 幾何與規則檢查（S1–S5） | 毫秒 | 每一個候選設計 |
| L1 | 簡化的 GPU 模型，以 L1b／L2 校正 | 1 分鐘內 | 大量篩選 |
| L1b | 完整 C3-C4 模型的 GPU 版（`gpufe`：與 FEBio 相同的網格和材料，真實的庫倫摩擦） | 10–30 分鐘 | 前段班 |
| L2 | 完整 FEBio 模型（已驗證的基準） | 數小時 | 最終候選；只有這一層的數字會當成正式結果 |

## 3. 最低限制

只固定「目的」、「手術」以及「脊髓、神經根、椎動脈和骨頭的安全」所必需的條件，其他一律自由。這份清單由安全守門者代理負責，任何修改都需要研究主持人同意（[`docs/PLAN.md`](docs/PLAN.md)、[`docs/DECISIONS.md`](docs/DECISIONS.md)）。

| 編號 | 限制 | 規則 |
|---|---|---|
| S1 | 只能在椎間隙內 | 位於向內縮 1 mm 的終板輪廓之內、上下終板之間 |
| S2 | 能從前方一次放入 | 植入時椎間高度最多暫時增加 2 mm（依手術技術指引訂定的預設值，待外科醫師確認）；**不修整終板骨頭**，只清理軟組織；植入過程中硬 PLCL 的應變 ≤ 3%，軟 PLCL ≤ 40% |
| S3 | 必須是一整塊 | 不能有鬆脫碎片（以免掉到脊髓附近；兩件式支架在體內塌陷） |
| S4 | 生物椎間盤空間 | 同時接觸上下終板，至少佔椎間隙體積的 50% |
| S5 | 可列印 | 最小結構 0.4 mm、層厚 0.2 mm、懸空角度 ≤ 45° |
| S6 | 承重能力 | 承受 1164 N 壓力而支架不破壞 |
| S7 | 維持高度 | 150 N 下高度損失 ≤ d/2 |
| S8 | 保護骨頭 | 終板接觸壓力低於以 FEBio 校正的下陷門檻 |
| S9 | **不滑出**（主要目標） | 摩擦係數 0.3 時（敏感度分析用 0.2／0.45）：相對 C3 和 C4，任何方向的位移 ≤ 1 mm；六個方向各 3 個循環，不能逐步累積；往脊髓方向 ≤ 0.5 mm，且往後推出力 ≥ 135 N |

**S2 背後的關鍵發現。** C3-C4 的終板是凹的（支架範圍內間隙 2.95–5.30 mm）。如果支架要填滿凹面，從前方滑入時需要額外暫時撐開 2.35 mm，否則最高的部位要被壓扁 35–41%；而硬 PLCL 大約在 5% 應變就會降伏。既然不修整骨頭，凹面就會保留下來，而阻擋植入的凹面，同樣也能阻擋滑出。因此，「硬骨架控制在可塞入的範圍內，再由軟 PLCL 回彈填滿凹面」是一類很值得讓演化去探索的設計。

## 4. 四個代理

每個代理都是獨立的背景 Claude（Opus 5.5）程序，各有自己的系統提示詞和寫入權限。完整規則見 [`docs/GOVERNANCE.md`](docs/GOVERNANCE.md)，參考了以下做法：獨立驗證與確效（NASA、IEEE 1012）、醫療器材設計審查的職責分離（ISO 13485）、多專家 AI 系統的黑板架構、固定格式交接（MetaGPT）、AI 安全辯論與紅隊演練、盲審、資料來源追蹤（W3C PROV），以及醫療器材模擬的可信度框架 ASME V&V 40。

| 代理 | 工作 | 擁有 | 權力 |
|---|---|---|---|
| **設計者** | 自由發想：新的編碼方式、設計程式、突變想法；以「通過檢驗的新穎設計」計分 | 設計提案 | 提出 |
| **驗證者** | 可靠與可重現：以固定亂數種子重跑抽樣、對照 FEBio 原始碼檢查程式、追蹤資料來源、檢查收斂與可信度關卡 | 測試套件、可信度關卡 | 可以**暫停**一輪 |
| **安全守門者** | 最低目的與解剖安全（脊髓、神經根、椎動脈、食道、骨頭）、手術可行性、支撐期間的材料劣化 | 限制清單 S1–S9（修改需研究主持人同意） | 可以**否決**設計 |
| **找漏洞者** | 攻擊所有人，包括整合者：模型漏洞、無法驗證的說法、遺漏的安全項目、管理規則的漏洞；每一項發現都附嚴重程度、可重現的證據和 2–3 個改善選項 | 漏洞登記簿 | 上報 |

**一輪的流程：** 設計者提案 → 引擎評估（L0 → L1 → L1b／L2）→ 驗證者審查（看不到設計者的推理，避免被說服）→ 安全守門者審查 → 找漏洞者攻擊 → 整合者（主要的 Claude 對話）執行裁定、回覆每一項發現，並為研究主持人寫摘要。只要驗證者暫停了這一輪，或還有嚴重發現沒解決，這一輪的結果就不採用。

**資料管理：** 每樣東西只有一個負責人。代理只能寫自己的工作區（`work/agents/<角色>/`）、共用公布欄上自己的裁定（`work/board/rNNNN/`），找漏洞者另外可以寫 `work/findings/`。交接一律用固定格式的 JSON；資料庫的紀錄不可修改，每個數字都附上程式版本、輸入檔指紋、亂數種子和設定。

**已知限制**（找漏洞者第一輪發現 F-0008）：權限可以限制代理的編輯工具，但被允許執行 Python 的代理，仍能以共用的系統帳號寫入任何位置。所以隔離目前一部分靠約定，而不是完全強制。

**第一輪成果（2026-10-26）：** 找漏洞者獨立找到母專案的一個負載曲線錯誤：前屈和後伸時，側彎與旋轉力矩其實也同時在增加，等於施加的是混合負載而不是純力矩。整合者確認後已修正。找漏洞者也發現 GPU 求解器的摩擦錨點問題（F-0003），以及實際使用的牛頓法求解器還沒通過任何關卡（F-0004）。安全守門者提出了現在 S9 中的往後限制，並提醒植入應變、長期潛變與材料劣化的問題。

## 5. 模擬方法

- **gpufe**（`gpufe/`）：以 PyTorch 撰寫的 GPU 有限元素求解器，直接讀取 FEBio 2.5 的輸入檔。材料公式逐條照 FEBio 4 原始碼移植：正交異性皮質骨、neo-Hookean 海綿骨與軟骨、Holmes-Mow 加纖維的纖維環、具三場公式與預應變的非耦合 Gent 支架材料，以及非線性韌帶彈簧。大型模型使用牛頓迭代：元素切線剛度以自動微分精確求得，再交給 cuDSS 稀疏直接求解器。接觸採用節點對面的罰函數法，搭配 FEBio 的庫倫黏著／滑動回推演算法，所以不會因為黏滑切換而不收斂；母專案當初正是因為這個問題，只好把支架黏死在骨頭上。
- **可信度關卡**（[`results/gpufe_verify/VERIFICATION.md`](results/gpufe_verify/VERIFICATION.md)）：(1) 和 FEBio 比對的均勻變形測試，所有材料誤差 < 1e-8；(1b) 非均勻平衡，誤差 < 2e-6；(1c) 方塊滑動與庫倫定律比對，誤差 ≤ 1.1%（FEBio 本身在摩擦係數 0.5 時只算到 0.457）；(2) 完整 C3-C4 節段的活動角度與小面關節力，和 FEBio 比對；(3) 有支架的案例，和 FEBio 比對；(4) 真實摩擦案例；(5) 準靜態檢查。第 2 到 5 關尚未完成。
- **滑出判斷的上下限**（`methods/e02_friction_limit.py`）：從「支架黏死在骨頭上」的解出發，防止滑出所需的摩擦係數介於兩個值之間：合力比值是樂觀的下限；另一個是同時要求扭轉也被摩擦扛住的線性規劃，屬於悲觀的上限（極限曲面理論）。真正的判定要靠真實摩擦模擬。

## 8. 限制與待解問題

- 只有一個個人化、左右理想對稱的 C3-C4 模型，尚未納入病人之間的差異。
- 找不到 PLCL 85:15 壓縮降伏，以及 PLCL 對骨頭摩擦係數的直接實測值；目前數值由類似材料推估，需要試片實驗確認。
- 尚未模擬隨時間變化的行為：潛變、夾緊力鬆弛、16–26 週的材料劣化。
- 植入限制是依手術技術指引訂定的預設值，待外科醫師確認。
- 代理之間的隔離有一部分靠約定（F-0008）。
